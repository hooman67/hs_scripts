## Diffusion Process Explained

> Diffusion models use a Fixed Markov chain. [cite: 2]
> At each step, we add some Gaussian noise to the image. [cite: 2]
> Then we pass the noisy image to the U-Net (as input) and use the noise that we just added as label. [cite: 3]
> We train the U-Net so that given a noisy image, it returns the noise that was added to it as output. [cite: 4]
> Ultimately, the image is asymptotically transformed to pure Gaussian noise. [cite: 5]
> And we have a noise predictor capable of estimating the noise added to an image. [cite: 6]
> In the reverse fusion part, we take a Gaussian noise image and ask the U-net to give us the noise. [cite: 7]
> We then subtract this estimated noise from the original image. [cite: 8]
> Repeat this process n times and we get the original image. [cite: 9]
> **Algo for stable diffusion:**
> –Feed the noise into the encoder (of VAE) to generate a random latent space matrix. [cite: 10]
> –Get the U-net (the noise predictor) to estimate the noise of the latent matrix. [cite: 11]
> –Subtract the estimated noise from the latent matrix. [cite: 12]
> –Repeat Steps 2 and 3 up to specific sampling steps. [cite: 12]
> –Use the decoder of VAE to convert the latent matrix to the final image [cite: 13]

## The `core_loop` Function

> The `core_loop` function is a key component of the diffusion denoising process. [cite: 14]
> It performs iterations of diffusion denoising by invoking a callable (`eps_callable`) representing a single step of the diffusion process. [cite: 14]
> **Setup and Initialization:**
> The function begins by setting up various parameters, schedules, and interfaces needed for the diffusion process. [cite: 15]
> It also initializes variables such as the initial image (`img`) and the predicted initial image (`predicted_x0_image`). [cite: 16]
> **Noise Initialization:**
> If configured, noise is added to the initial image based on the provided Gaussian noise (`randn_noise`). [cite: 17]
> The noise addition depends on the scheduling of noise and the specific iteration index. [cite: 18]
> **Scheduling and Iterations:**
> The function uses a scheduler (`sampler`) to determine the timesteps for diffusion. [cite: 19]
> It iterates through these timesteps, performing the diffusion process at each step. [cite: 20]
> If a binary mask is provided, it modifies the image based on the mask during specific iterations. [cite: 21]
> **Guidance and Regularization:**
> The guidance function (`guidance_fn`) is employed to guide the diffusion process. [cite: 22]
> This function incorporates various guidance mechanisms, such as classifier guidance, sparsity regularization, and wavelet regularization. [cite: 23]
> Classifier guidance is applied to the image using a specific function (`saturation_regularization`). [cite: 24]
> **Callback Function:**
> If a callback function is provided, it is called at each iteration to report intermediate results. [cite: 25]
> This can be useful for monitoring the progress of the diffusion process. [cite: 26]
> **Iteration Output:**
> After each iteration, the function records the current iterate (`img`) and the predicted initial image (`predicted_x0_image`). [cite: 27]
> These outputs are then returned in a `CoreResult` object. [cite: 28]
> **Final Result:**
> The final result includes the iterates, predicted initial image, and optionally, any model outputs generated by the sampler during the iterations. [cite: 28]
> **Return:**
> The function returns a `CoreResult` containing the iterates, predicted initial image, and sampler model outputs. [cite: 29]
> This function essentially encapsulates the core logic of the diffusion denoising process, orchestrating the iterations, incorporating guidance and regularization, and providing flexibility through callbacks and configurable parameters. [cite: 30]
> **HS:**
> `model_output` is the predicted noise from the U-Net. [cite: 31]
> `predicted_x0_image` is the final output its the predicted image at time step 0. [cite: 31]
> `prev_sample` (`torch.FloatTensor` of shape `(batch_size, num_channels, height, width)` for images): Computed sample `(x_{t-1})` of previous timestep. [cite: 31, 32]
> `prev_sample` should be used as next model input in the denoising loop. [cite: 32, 33]

```python
import copy
import logging
from collections.abc import Callable
import torch
from tqdm import tqdm
from clio.typings.guidance_interface import GuidanceCallable, GuidanceInterface
from clio.typings.interface import (
    ConditionTensors,
    CoreCallbackInterface,
    CoreParameters,
    CoreResult,
)
from clio.typings.samplers_interface import SetTimestepsInterface, StepInterface
from clio.typings.typings import AdaptorsCallable, ClassifierGuidance, EpsCallable
from .guidance import guidance
from .guidance.cfg_schedule import cfg_schedule
from .guidance.guidance import saturation_regularization
from .samplers import schedules
from .samplers.eta_schedule import eta_schedule

def core_loop(
    eps_callable: EpsCallable,
    initial_image: torch.Tensor,
    randn_noise: list[torch.Tensor],
    inputs: ConditionTensors,
    avoids: ConditionTensors,
    params: CoreParameters,
    controlnet_adaptors: list[AdaptorsCallable] | None = None,
    binary_mask: torch.Tensor | None = None,
    classifier_guidance: ClassifierGuidance | None = None,
    sampler_model_outputs: list[torch.Tensor] | None = None,
    callback: Callable[[CoreCallbackInterface], None] | None = None,
) -> CoreResult:
    """
    Core base diffusion denoising loop. This function assumes all tensors
    are batched and in the correct device. This function does NOT perform
    argument checking.
    NOTE: ConditionTensors are converted into a dictionary that is passed into
          EpsCallable. It is expected that the provided eps_callable handles
          the unpacking of said dictionaries. It is likely that your
          eps_callable does _not_ use all entries, but that is fine -- just
          leave them as None and do not unpack them.
    Parameters:
        - eps_callable:
            Callable that implements a single step of diffusion denoising.
            Typically a u-net.
        - initial_image:
            Image to start iterations from. Set to a tensor of zeros if running
            baseline text to image. Otherwise, this is the starting point for
            image variations akin to SDEdit. The expected range of values is
            [-1, 1]. Expected dimensions are: (batch, channels, height, width).
        - randn_noise:
            Pre-defined Gaussian noise to use during iterations. This is to be
            predefined as otherwise it is not easy to run batch inference for
            multiple noise seeds.
        - inputs:
            Tensors that the eps_model or unet are conditioned on. This directs
            the generation.
        - avoids:
            Tensors that the eps_model or unet are conditioned on. This is the
            "anchor" prompt and reflects the conditions to move away from.
        - params:
            Required non-tensor parameters for the diffusion loop.
        - binary_mask:
            Binary mask as a torch tensor. Regions within the mask are expected
            to be 1 with the background being 0. Expected dimensions are:
            (batch, 1, height, width) or (num_iters, batch, 1, height, width).
        - sampler_model_outputs:
            When jump-starting core_loop but using a sampler like UniPC, the
            previous iterates are needed for good results.
        - callback:
            Function to return intermediate results. This function returns
            None. The inputs to this functions are described in CoreCallable.
            All images are torch tensors with values in the range [-1, 1] that
            can be converted to PIL Images. ratio is a float between 0 and 1
            calculated as follows:
                ratio = current_iteration_idx / total_number_of_iterations.
            Using a ratio allows callbacks to be robust to the change in total
            number of iterations when either early ending or initializing the
            de-noising loop with the initial_image akin to SDEdit.
        Returns:
        - images:
            Batched image generations as tensors with in range [-1, 1].
    """
    verbosity = params.verbosity
    if verbosity >= 2:
        logging.info("[CORE] Parameters passed to CORE: %s", params)
    randn_noise = copy.copy(randn_noise)  # Making a copy of the list to use pop.
    # Set up of scheduler/ sampler. For more information, please see the second
    # talk here: [https://www.youtube.com/watch?v=cS6JQpEY9cs](https://www.youtube.com/watch?v=cS6JQpEY9cs)
    sampler = schedules.get_schedule(
        schedule_type=params.sampling_parameters.schedule_type,
        prediction_type=params.sampling_parameters.prediction_type,
        beta_schedule=params.sampling_parameters.beta_schedule,
        beta_0=params.sampling_parameters.beta_0,
        beta_1=params.sampling_parameters.beta_1,
        max_beta=params.sampling_parameters.max_beta,
        training_timesteps=params.sampling_parameters.training_timesteps,
        hybrid_transition=params.sampling_parameters.hybrid_transition,
        first_again_after_timestep=params.sampling_parameters.first_again_after_timestep,
        dynamic_thresholding_ratio=params.sampling_parameters.dynamic_thresholding,
        first_sampler=params.sampling_parameters.first_sampler,
        second_sampler=params.sampling_parameters.second_sampler,
        solver_order=params.sampling_parameters.solver_order,
        zero_terminal=params.sampling_parameters.zero_terminal,
        tolerance=params.sampling_parameters.eps_tolerance,
        mask=None
        if binary_mask is None
        else binary_mask
        if len(binary_mask.shape) == 4
        else binary_mask[0],
        momentum_beta=params.sampling_parameters.momentum_beta,
    )
    assert hasattr(sampler, "betas") and sampler.betas is not None
    sampler.model_outputs = (
        sampler_model_outputs if sampler_model_outputs is not None else []
    )
    sampler_params = StepInterface(
        noise_list=randn_noise,
        eta_fn=eta_schedule.get_eta_schedule(
            base_eta=params.sampling_parameters.base_eta,
            eta_schedule_type=params.sampling_parameters.eta_schedule_type,
            use_zero_eta_after_timestep=params.sampling_parameters.use_zero_eta_after_timestep,
        ),
    )
    sampler.set_timesteps(
        SetTimestepsInterface(
            num_inference_steps=params.iteration_parameters.num_iters,
            skip_type=params.sampling_parameters.skip_type,
            timesteps_start_ratio=params.sampling_parameters.timesteps_start_ratio,
            timesteps_end_ratio=params.sampling_parameters.timesteps_end_ratio,
            training_content_param=params.sampling_parameters.training_content_param,
            inference_content_param=params.sampling_parameters.inference_content_param,
            betas=sampler.betas,
        )
    )
    if params.verbosity > 1:
        logging.info("Timesteps: {}".format(" ".join(map(str, sampler.timesteps))))
    # Set up guidance function. Please see [https://arxiv.org/abs/2207.12598](https://arxiv.org/abs/2207.12598) for an
    # example of the most commonly used guidance function, which is classifer free
    # guidance.
    guidance_fn: GuidanceCallable = guidance.get_guidance_function(
        params.guidance_parameters.guidance_type
    )
    # TODO: change cfg_schedule to be all the same interface
    # rename to inference_schedule utils or something like that
    guidance_schedule_fn = cfg_schedule.get_cfg_schedule(
        params.guidance_parameters.cfg_schedule
    )
    phi_fn = (
        cfg_schedule.get_cfg_schedule(params.guidance_parameters.stdev_phi)
        if params.guidance_parameters.stdev_phi is not None
        else None
    )
    sparsity_regularization_fn = (
        cfg_schedule.get_cfg_schedule(
            params.guidance_parameters.sparsity_regularization
        )
        if params.guidance_parameters.sparsity_regularization is not None
        else None
    )
    sharpness_regularization_fn = (
        cfg_schedule.get_cfg_schedule(
            params.guidance_parameters.sharpness_regularization
        )
        if params.guidance_parameters.sharpness_regularization is not None
        else None
    )
    wavelet_regularization_fn = (
        cfg_schedule.get_cfg_schedule(params.guidance_parameters.wavelet_regularization)
        if params.guidance_parameters.wavelet_regularization is not None
        else None
    )
    saturation_regularization_fn = (
        cfg_schedule.get_cfg_schedule(
            params.guidance_parameters.saturation_regularization
        )
        if params.guidance_parameters.saturation_regularization is not None
        else None
    )
    # Make a variable copy of initial_image to simplify following if statements.
    (img, predicted_x0_image) = (initial_image,) * 2
    # Looping parameters.
    num_iters = params.iteration_parameters.num_iters
    sample_interval = params.iteration_parameters.sample_intervals
    assert len(sample_interval) == 2
    (itr_idx_loop_start, itr_idx_loop_end) = (
        (round(elm * num_iters)) for elm in sample_interval
    )
    if params.iteration_parameters.masking_interval is not None:
        mask_interval = params.iteration_parameters.masking_interval
        assert len(mask_interval) == 2
        (itr_idx_mask_start, itr_idx_mask_end) = (
            (round(elm * num_iters)) for elm in mask_interval
        )
    else:
        (itr_idx_mask_start, itr_idx_mask_end) = (None,) * 2
    # Since the diffusion iterations might be jump-started, we have to add the
    # appropriate level of noise.
    if params.iteration_parameters.add_noise_to_initial_image:
        img = sampler.add_noise(
            img,
            randn_noise.pop(0),
            sampler.timesteps[itr_idx_loop_start]
            if isinstance(sampler.timesteps, torch.Tensor)
            else torch.tensor(sampler.timesteps[itr_idx_loop_start]),
        )
    timesteps = sampler.timesteps[itr_idx_loop_start:itr_idx_loop_end]
    if verbosity > 0:
        timesteps = tqdm(
            timesteps,
            desc="CORE",
        )
    len_timesteps = len(timesteps)
    # Iterations.
    for loop_idx, time_val in enumerate(timesteps):
        binary_mask_at_idx = (
            None
            if binary_mask is None
            else binary_mask
            if len(binary_mask.shape) == 4
            else binary_mask[loop_idx]
        )
        if (
            binary_mask_at_idx is not None
            and itr_idx_mask_start is not None
            and itr_idx_mask_end is not None
            and loop_idx >= itr_idx_mask_start
            and loop_idx < itr_idx_mask_end
        ):
            forward_img = sampler.add_noise(
                initial_image,
                randn_noise.pop(0),
                torch.tensor(time_val),
            )
            img = binary_mask_at_idx * img + (1 - binary_mask_at_idx) * forward_img
        img_input = sampler.scale_model_input(img, time_val)
        guidance_interface = GuidanceInterface(
            guidance_parameters=params.guidance_parameters,
            eps_model=eps_callable,
            controlnet_adaptors=controlnet_adaptors,
            positive_conditions=inputs,
            negative_conditions=avoids,
            iter_img=img_input,
            iter_idx=loop_idx,
            time_val=time_val,
            n_inference_timesteps=len_timesteps,
            guidance_schedule_fn=guidance_schedule_fn,
            phi_fn=phi_fn,
            sparsity_regularization_fn=sparsity_regularization_fn,
            wavelet_regularization_fn=wavelet_regularization_fn,
            saturation_regularization_fn=saturation_regularization_fn,
            sharpness_regularization_fn=sharpness_regularization_fn,
            classifier_guidance=classifier_guidance,
        )
        # Noise prediction.
        noise_pred = guidance_fn(guidance_interface)
        # Compute the previous sample, i.e., going from x_t to x_t-1.
        sampler_params.model_output = noise_pred
        sampler_params.timestep = time_val
        sampler_params.sample = img

'''
        Predict the sample from the previous timestep by reversing the SDE.
        This function propagates the sample with
        the multistep DEIS.
        Args:
            model_output (`torch.FloatTensor`):
                The direct output from learned diffusion model.
            timestep (`float`):
                The current discrete timestep in the diffusion chain.
            sample (`torch.FloatTensor`):
                A current instance of a sample created by the diffusion process.
            return_dict (`bool`):
                Whether or not to return a [`~schedulers.scheduling_utils.SchedulerOutput`] or `tuple`.
            prev_sample (`torch.FloatTensor` of shape `(batch_size, num_channels, height, width)` for images):
                Computed sample `(x_{t-1})` of previous timestep. `prev_sample` should be used as next model input in the denoising loop.
        '''
        val = sampler.step(sampler_params)
        img = val.prev_sample
        predicted_x0_image = (
            val.pred_original_sample
            if hasattr(val, "pred_original_sample")
            else sampler.convert_model_output(noise_pred, time_val, img)
            if (loop_idx < params.iteration_parameters.num_iters - 1)
            and hasattr(sampler, "convert_model_output")
            else val.prev_sample
        )
        # Apply classifier guidance
        img = saturation_regularization(
            iterate=img, guidance_interface=guidance_interface
        )
        if callback:
            ratio = loop_idx / len_timesteps
            callback(
                CoreCallbackInterface(
                    ratio=ratio,
                    predicted_image=img.detach().clone(),
                    predicted_x0_image=predicted_x0_image.detach().clone(),
                    loop_index=loop_idx,
                    diffusion_timestep_value=time_val,
                    timesteps=sampler.timesteps.detach().clone()
                    if isinstance(sampler.timesteps, torch.Tensor)
                    else torch.Tensor(sampler.timesteps),
                    inputs=inputs.copy(deep=True),
                    avoids=avoids.copy(deep=True),
                    params=copy.deepcopy(params),
                )
            )
        if verbosity > 1:
            logging.info(f"Iteration: {loop_idx}, Sampling time: {time_val}.")
    sampler_model_outputs = (
        sampler.model_outputs if hasattr(sampler, "model_outputs") else None
    )
    bitmask = params.return_bitmask
    return CoreResult(
        iterates=img if bool(bitmask & 1) else None,
        predicted_x0_image=predicted_x0_image if bool(bitmask & 2) else None,
        sampler_model_outputs=sampler_model_outputs if bool(bitmask & 4) else None,
    )
```
