# Interview Process — Foundry Generative Models

> **Status: v1 (2026-07-06), Hooman's rules.** The panel structure, screening rubric, and
> reviewer expectations every candidate runs through. Pairs with `profile.md` (who we want)
> and `candidates.md` (who we've seen). Interview loop starts *after* a candidate clears the
> initial screen.

## Panel — 5 interviews per candidate

Every candidate gets **five** interviews:

| # | Type | Interviewers (any of) |
|---|------|-----------------------|
| 1 | **Coding round 1** | @hoshyari / @arpmathu / @sharmaa / @charagon |
| 2 | **Coding round 2** | @skatakol / @mbrack |
| 3 | **Technical — fundamentals** | @haravi |
| 4 | **Technical — system design** | @skatakol / @mbrack / @pranagga |
| 5 | **Technical — data deep dive + behavioural** | @pranagga / @miranda / @haravi |

- **2 coding rounds**, **1 fundamentals**, **1 system design**, **1 data-deep-dive + behavioural.**

### Coding rounds — NOT leetcode
- Coding rounds **must not** be leetcode-style. They are **general modelling** problems.
- There is a **notebook of example problems** we reuse — **@pranagga can point to it.**

## Initial screening (done by Hooman, the `/hiring` skill, or a delegate)

Before the panel, a ~30–40 min screen covering:

- **10 min — technical** (sanity-check the core skills claimed on the resume).
- **10 min — experience** (walk their actual E2E ownership, not the résumé bullets).
- **10–20 min — culture fit.** The candidate needs to be:
  - a **collaborator**,
  - able to **listen**,
  - **responsible**,
  - **takes initiative** (go-getter).

## Culture-fit-over-skills principle (decisive tie-breaker)

> **A slightly-irrelevant skillset + strong culture fit outweighs a bad culture fit + very
> strong skills** — *unless* we believe we can make that person behave well.

Culture fit is not a soft add-on; it can flip the decision against a stronger-on-paper candidate.

## Reviewer requirements (mandatory for every interviewer)

Every interviewer **MUST** submit a detailed written review containing:

- **Notes on every question asked and every answer given** by the candidate.
- A **rating out of 10.**
- A **hire / no-hire** call **for the intended level.**
- Any **additional notes or suggestions.**

> Hooman has example reviews on file to use as templates — ask him to point to them.
