# Fremont MLS Export Request

Please provide two separate CSV or XLSX exports for detached single-family homes with at least three bedrooms in Fremont, California:

1. Current Active, Contingent/Active-under-contract, and Pending listings, with each source status preserved.
2. Closed listings from the most recent 12 months. If a submarket is sparse, also provide a separate 13–24-month export rather than combining the periods.

Please include these fields where the MLS license permits:

```text
mls_name, mls_number, status, property_subtype, full_address, apn,
latitude, longitude, list_date, pending_date, close_date,
original_list_price, current_list_price, close_price,
bedrooms, bathrooms, living_area_sqft, lot_sqft, year_built,
hoa_monthly, dom, continuous_dom, sale_or_special_condition,
public_remarks, source_exported_at
```

Please also state any restrictions on storing, retaining, quoting, or redistributing the export. Do not include confidential agent remarks or occupant information.

The working price-discovery band is USD 750,000–1,050,000, but a slightly wider export is preferable so the analysis can distinguish true scarcity from a narrow filter.
