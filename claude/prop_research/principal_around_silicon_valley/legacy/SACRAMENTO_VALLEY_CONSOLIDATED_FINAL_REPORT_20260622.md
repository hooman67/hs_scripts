## Section 4: Source Citations & Confidence Attribution

### Data Collection Methodology

#### HIGH Confidence Sources
1. **Zillow.com & Redfin.com**
   - Use: Median prices, lot sizes, current listings
   - Confidence: HIGH if data from June 2026, MEDIUM if from May or earlier
   - URL template: https://www.zillow.com/homes/for_sale/[CITY]-CA/

2. **Census Bureau (data.census.gov)**
   - Use: Racial/ethnic demographics, % non-white residents
   - Confidence: HIGH if ACS 2024 data, MEDIUM if 2023
   - URL: https://data.census.gov

3. **FBI Uniform Crime Reporting (UCR)**
   - Use: Violent crime, property crime (per 1,000 residents)
   - Confidence: HIGH if 2024-2025 data available
   - URL: https://crime-data-explorer.fbi.gov

4. **GreatSchools.org**
   - Use: School ratings, school count, diversity index
   - Confidence: HIGH for API data, MEDIUM for aggregated
   - URL: https://www.greatschools.org

5. **Cal Fire State Responsibility Area (SRA) Maps**
   - Use: Fire zone classifications
   - Confidence: HIGH (official government)
   - URL: https://www.fire.ca.gov

6. **USDA Plant Hardiness Zone Map**
   - Use: Growing season, frost-free days
   - Confidence: HIGH (official government)
   - URL: https://planthardiness.ars.usda.gov

#### MEDIUM Confidence Sources
1. **NeighborhoodScout.com**
   - Use: Crime rates (backup), community vibe
   - Confidence: MEDIUM (aggregated from public sources)
   - URL: https://www.neighborhoodscout.com

2. **Google Maps / Waze**
   - Use: Commute times (off-peak)
   - Confidence: MEDIUM (real-time but variable)
   - Note: Must verify during off-peak hours

3. **USGS Hazard Viewer**
   - Use: Flood zones, earthquake risk
   - Confidence: MEDIUM (official but regional averages)
   - URL: https://hazards.usgs.gov

4. **County Assessor Records**
   - Use: Property sales, lot sizes
   - Confidence: MEDIUM (historical data)

#### LOW Confidence Sources
- Local blogs, Reddit communities (for vibe only, not metrics)
- Single-source or outdated listings
- User-generated content without official verification

### Data Quality Assurance Procedures

1. **Cross-reference thresholds:**
   - Prices: Flag if >10% variance between Zillow/Redfin
   - Crime: Flag if >20% variance between sources
   - Demographics: Use most recent Census data available

2. **Currency verification:**
   - All data points labeled with collection date
   - Data from 2024-2026 preferred (2023 acceptable with note)
   - Data before 2023 flagged as outdated

3. **Completeness:**
   - Any missing data point marked "DATA NOT FOUND"
   - Assigned LOW confidence
   - Alternative sources identified for follow-up
