================================================================================
TIPS TO SAVE TIME
================================================================================

1. Batch similar towns: Visit all 8 Zillow pages in one go (10 min)
   Then visit all 8 Redfin pages (10 min)
   → Faster than switching back and forth

2. Keep JSON template open: Paste data immediately after each town
   → Reduces re-reading and confusion

3. Use browser tabs: Zillow in tab 1, Redfin in tab 2, JSON in tab 3
   → Quick switching

4. Email agents EARLY: Send emails while doing Zillow/Redfin work
   → Responses will arrive while you research other sources

5. Screenshot method: Take screenshots of market pages
   → Proves data recency, prevents re-visiting

================================================================================
COMMON MISTAKES TO AVOID
================================================================================

[ ] Recording "1950k" instead of "$1,950,000" → Use consistent format
[ ] Using overall median when 3BR data is available → Always filter for 3BR
[ ] Mixing 2024 data with 2025-2026 data → Check dates!
[ ] Using list prices instead of sold prices → Sold prices are real transactions
[ ] Recording single source only → Get 2-3 sources for validation
[ ] Not checking if price seems reasonable → Catch errors early
