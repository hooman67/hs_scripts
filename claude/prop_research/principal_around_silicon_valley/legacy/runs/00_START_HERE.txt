TROUBLESHOOTING
================================================================================

Q: Which option should I do?
A: Start with OPTION A (20-30 min) to get baseline data. If you're serious
   about this $2M purchase, expand to OPTION B to add MLS data (HIGH confidence).

Q: Zillow showing "403 Forbidden"?
A: Try incognito browser mode or clear cache. Or skip to Redfin + MLS.

Q: How long does this take?
A: OPTION A (Zillow+Redfin): 20-30 min | OPTION B (add MLS): 1-2 hours total

Q: Do I have to do all 8 towns?
A: Yes. This is foundational data for your entire Peninsula region analysis.

Q: Can I use older data (2024)?
A: Try to avoid. Use 2025-2026 only. If forced, mark clearly as "Prior Year."

Q: What if agent doesn't respond?
A: Try calling instead of emailing. Or try a different agent.

More answers: See MARKET_RESEARCH_GUIDE.md
