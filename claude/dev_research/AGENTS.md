# Durable Resume Rule

This is a long-running career-readiness research project. At the start of every new or
resumed session:

1. Read the complete research playbook at `/home/colligo/.codex/RESEARCH_RULES.md` for Codex or
   `/home/colligo/.claude/RESEARCH_RULES.md` for Claude, and verify the real checkout is under
   `/home/colligo`. Then read `CLAUDE.md`, `PROJECT_STATE.md`, `DECISIONS.md`, `LEARNINGS.md`, and
   `LONG_TERM_PLANS.md`.
2. Treat `PROJECT_STATE.md` as the exact live handoff. Continue from its next action; do
   not restart completed research.
3. Use bounded research batches and update `PROJECT_STATE.md` after every substantive
   batch with completed scope, findings, open gaps, and the next exact step.
4. Update `DECISIONS.md`, `LEARNINGS.md`, and `LONG_TERM_PLANS.md` whenever the work changes
   their contents. Do not infer that Hooman accepted a recommendation.
5. Follow the evidence and confidence rules in `research-plan.md`. Never turn an
   assumption or a job-posting pattern into a fact.
6. Keep files few, topic-organized, and readable without chat history. Add a topic folder
   only when that research begins; each topic gets one canonical summary.
7. Parallelize only independent work. Keep synthesis and edits to shared files centralized.
8. Do not publish, apply, message, post, or edit an external profile without Hooman's
   explicit approval.
9. Whenever mentioning a file to Hooman, always use its full absolute filesystem path. Never
   mention or link to a file using a relative path.

## Resume without recreating obsolete work

- Follow the teaching rules in `/home/colligo/hs_scripts/claude/dev_research/CLAUDE.md`: explain
  the big picture with diagrams and examples before failure mechanisms, define new terms on first
  use, and separate interview rehearsal. Introductory tutorials may be read before an attempt.
- Use the file index in `/home/colligo/hs_scripts/claude/dev_research/CLAUDE.md` to find the current
  curriculum, first exercise, positioning proposal and topic references. Open those exact files;
  do not regenerate them merely because a new session started.
- Use `/home/colligo/hs_scripts/claude/dev_research/PROJECT_STATE.md` for the latest user request,
  completed work, remaining approvals and exact next action. Reading a plan is not evidence that
  Hooman completed an exercise or approved profile changes.
- Preserve source manifests and dated research evidence. Old paths in historical manifests are
  provenance, not instructions to recreate missing inputs or the former folder layout.
- The abandoned browser launcher and old cycle/week folder were removed deliberately. Do not
  reinstall or restart remote browser infrastructure during routine project resume.
