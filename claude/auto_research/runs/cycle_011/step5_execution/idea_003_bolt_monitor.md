# Execution Plan: IoT Bolt Tension Monitor for Wind Turbines

## Summary
- **Value prop**: Continuous bolt monitoring prevents $3-10M tower collapse events
- **Hardware**: Strain gauge washer ($20) + wireless node ($30) + gateway ($500) = ~$50-100/bolt
- **SaaS**: $200/turbine/month for monitoring + alerting
- **Capital needed**: ~$450K (hardware design + ruggedization + wind farm pilot, 9 months)
- **Target customers**: Wind farm operators (NextEra, Ørsted, Enel), turbine O&M providers
- **Revenue Year 1**: 500 turbines × $200/mo × 8mo = **$800K ARR run rate**
- **Key moat**: Ruggedized hardware qualified for wind environments + failure prediction ML
