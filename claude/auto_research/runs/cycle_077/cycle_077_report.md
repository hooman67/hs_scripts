## Step 2 MOAT GATE + Step 3 SAM (why the plant reframe also fails)

1. **The underlying data is PUBLIC-record aggregation, not uniquely accumulable.** All these services
   "aggregate multiple databases" — USCG documentation, state title/registration, federal accident
   records — that any competitor can equally pull. This is the exact failure the Round-4 map warned
   about for the well-log plant ("states publish logs as open public data → commoditizes the plant").
   Unlike a title plant (a legal, closed, county-recorder funnel), boat records are open and already
   aggregated by 5+ brands → **no defensible founder-owned moat.**
2. **The surveyor-condition layer (#2) has no funnel.** To make condition data flow into the plant you'd
   need surveyors to contribute — but they're only ~1,000–2,000 accredited seats (cycle 074), each
   already on a competing $30/mo report app, with no incentive to hand their client's paid report to a
   shared plant. No network-effect ignition. **Moat FAILS.**
3. **Buyer/SAM mismatch**: the plant's buyer is the *consumer* buying one boat once (a $20–100 one-off
   report) — a low-frequency, low-LTV consumer transaction in a market of ~1M used-boat sales/yr, split
   across 5+ incumbents. This is consumer SEO-content adjacent (LEARNINGS.md: "consumer SEO content is
   structurally broken — Google HCU/AI Overviews, race to zero; reject on sight"). Not a fragmented-
   private-*operator* SaaS; not a >$100M defensible founder SAM.

**Verdict: FAIL** on moat (public-record aggregation, already done ×5) and buyer/market (one-off consumer
report, race-to-zero) and no surveyor-contribution funnel.

by a different tool each transaction; valuation data is a pre-owned API monopoly; commercial data
funnels to the operator SoR / class society; and the public-record plant is open to all. There is no
CutLog-style "same operator generates the same proprietary data every working day" funnel here.

deep research (Step 6). This is a valid, expected honest-zero (9 of 10 domains zeroed in Round 3);
