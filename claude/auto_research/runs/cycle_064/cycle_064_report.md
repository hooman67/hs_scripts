- **Free public data (VERIFIED):** CA-DWR well completion reports (public-domain, geologic logs +
  casing + per-well PDFs, CSV/ArcGIS), TX-TWDB SDR (full reports 2003–present, shapefile + DB
  exports), USGS NWIS national groundwater data. Any product in #1, #2, #4, #5, #10 is built on

- **DrillerDB Well Map (VERIFIED):** already aggregates **18M+ well records from all 50 states'
  archives, free.** This is the "Zillow for wells" — already built and given away. Kills #1, #10.
- **WellDatabase (VERIFIED):** proves subsurface-log aggregation is a real commercial category —
  but in **oil&gas**, already owned, and its existence shows the pattern is picked. In water,
  the state + DrillerDB already give it away, so there's no room to charge.
- **Moat verdict:** REJECT all data-product ideas. The founder cannot uniquely accumulate what
  the government publishes and DrillerDB re-aggregated for free. The only proprietary increment
  (enrichment/prediction) is a thin feature on a free base — absorbable, not a company.
