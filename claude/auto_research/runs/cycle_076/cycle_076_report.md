# Cycle 076 Report — Steelman #1: recurring COMMERCIAL vessel surveys (does data funnel?)

**Date**: 2026-07-09
**Domain (Round 4 map #6, steelman)**: The core kill in cycle 074 was that recreational condition
data never funnels to one accumulator (each transaction re-surveyed by a different tool). This cycle
tests the strongest counter-hypothesis: **recurring, mandated COMMERCIAL vessel surveys** (USCG
Certificate of Inspection annuals, class-society periodic surveys) — where the SAME vessel is
inspected on a fixed cadence, so a platform *could* accumulate a genuine longitudinal per-hull record.
Does that rescue the moat and SAM?
**Agent**: Round-4 discovery Agent F.

**Mandatory gates**: incumbent/OEM, moat-to-founder, growth+SAM, fragmented-private-buyer.

## Step 2 MOAT GATE + Step 3 BUYER GATE (the decisive failures)

Even though data *does* recur here, the moat and buyer gates fail hard:

1. **The accumulated record accrues to the FLEET OPERATOR's SoR (Binnacle/OceansHQ) or the CLASS
   SOCIETY — not the founder.** Recurring surveys funnel into the operator's compliance system of
   record or ABS/DNV class files. This is the exact Round-3 pattern: "layer AI on the incumbent SoR's
   data" → moat accrues to the SoR, not the founder. **Moat FAILS.**
2. **BUYER GATE FAIL — this pivots to the instant-reject buyer.** Commercial marine compliance buyers
   are fleet operators (enterprise, 12–24 mo procurement) and, upstream, USCG/OCMI + class societies
   (regulator/quasi-utility). This is the government/utility/enterprise buyer the Round-4 map calls an
   instant reject — the opposite of the fragmented private surveyor thesis. Moving from recreational
   to commercial *solves* the accumulation problem only by *breaking* the fragmented-private-buyer gate.
3. **SAM**: US inspected commercial fleet is a countable universe (Subchapter M towing ≈ 5,600 vessels /
   ~1,000 operators; total USCG-inspected fleet tens of thousands but concentrated in a few hundred
   operators). Even at enterprise ACVs the reachable seat/operator base is small and already contested
   by Binnacle/OceansHQ. Not a clean >$100M founder-addressable SAM, and gated behind enterprise sales.

**Verdict: FAIL on moat (accrues to operator SoR / class society) AND buyer (enterprise/regulator).**
The recurring-cadence steelman does not save the domain — it just relocates the moat to the incumbent
and swaps the fragmented-private buyer for the instant-reject enterprise/regulator buyer.
