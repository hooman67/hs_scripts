# Execution Plan: AI Asphalt Paving Quality System

## Summary
- **Value prop**: Real-time thermal QC for paving operations — catch cold spots before they become $50K road failures
- **Hardware**: FLIR Lepton 3.5 ($200) + GPS ($10) + Raspberry Pi ($60) + weatherproof enclosure ($50) = $320 BOM, sell in kit at $5K (installed on paver)
- **SaaS**: $300/month (thermal maps, QC reports, DOT-format submission)
- **Capital needed**: ~$300K (thermal imaging + GPS integration + pilot with paving contractors, 7 months)
- **Target**: DOT highway contractors, municipal paving companies
- **Revenue Year 1**: 100 kits × $5K + 100 × $300/mo × 6mo (seasonal) = $500K + $180K = **$680K**
- **Regulatory tailwind**: FHWA Intelligent Compaction mandates; Texas, Minnesota, Indiana DOTs already require thermal profiling on some projects
- **Competition**: MOBA (German, $expensive), Pave-IR (manual handheld, no AI). Nobody does AI-powered continuous thermal analysis with automated report generation at this price point.
