Select photographic reference candidates for the ORIGINAL user request.
All candidates have user-provided human/no_humans tags. The contact sheets show
actual photographs with IDs; metadata supplies scene tags and measured exposure.
Set human_policy="human" ONLY when the original request explicitly asks for people,
such as a woman, man, coworkers, workers, family or a visible user. Otherwise use
"no_humans", including explicit no-people requests. "Lived-in", a home workspace,
a cafe or empty chairs do not request people. Rank only references with matching
human_presence tags. Use the existing tags; do not infer or reannotate presence.

Choose up to eight IDs in ranked order, considering actual room, lighting,
brightness and palette. Select a supplied content category and tone. Warm wood,
dark walnut and dark walls do NOT specify warm illumination or a dim room.
Explicit natural daylight can be Natural Daylight. An explicitly bright/airy home
must not receive a dark spotlighted bedroom. Distinguish bedroom and home office.
Tone tags are coarse hints; actual photographic style matters. Brightness means
ROOM ILLUMINATION, not paint or furniture color. Code applies human-tag and
scene/brightness eligibility before the final choice, with no cross-tag fallback.
