**Layers:** `raw/` = immutable sources (Hooman's `hs_scripts/docs` notes are symlinked at `raw/docs`; ~45 md files across asml_notes, glimmer, colligo, foundry, guides; plus `raw/llm-wiki.md`). `wiki/` = LLM-owned synthesis (`overview.md`, `entities/`, `concepts/`, `sources/`, `analysis/`). Root nav: `index.md` (catalog), `log.md` (append-only, `## [date] op | title`), `WIKI_SCHEMA.md` (the config the skills read first).

**Skills** (in dotclaude/commands, prefix `obs-`, plain-markdown instruction skills — no Python): `/obs-ingest` (read raw source → summary + entity/concept pages → update index+log), `/obs-query` (answer from wiki w/ citations, file answer back to `wiki/analysis/`), `/obs-search` (ripgrep `-L` + obsidian MCP search over wiki/raw), `/obs-lint` (contradictions/orphans/dead-links/index-drift; `--fix` for mechanical repairs), `/obs-index` (rebuild index.md from wiki).

**Conventions:** kebab-case filenames, YAML frontmatter (type/title/tags/created/updated/sources), `[[wikilinks]]` both directions, contradictions flagged with `> [!warning] Contradiction` never silently overwritten, dates from session currentDate. Prefer direct file tools over MCP; use MCP `open_file` to surface pages live.

**Gotchas:** `raw/docs` is a symlink → ripgrep needs `-L`. Skip `raw/docs/candidates.md` (hiring PII) from ingests. `wiki-` prefix was taken by Confluence skills, hence `obs-`. Seed ingest (Karpathy doc) is self-documentation of the system. Frontmatter standardized on `created`/`updated` (`ingested` optional, == created).
