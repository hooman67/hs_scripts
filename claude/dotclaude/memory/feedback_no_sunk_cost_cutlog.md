In the auto_research secondary-income project, Hooman corrected me: "You're overindexing on
CutLog. I don't mind abandoning CutLog if there is something better." He is NOT sunk-cost
attached to CutLog (his live laser-cutting SaaS, see [[project_cutlog]]).

**Why:** I had let "don't split focus from CutLog" become a hidden penalty against every new
idea, and had never subjected CutLog itself to the same adversarial validation I applied to
alternatives — an unfair asymmetry that protected the incumbent choice.

**How to apply:** Rank options flat, on merit, with CutLog as just one candidate for his single
"serious venture" slot — not a fixed baseline. Apply equal skepticism to the thing already in
flight. When comparing a new idea to an existing project, stress-test both with the same rigor.
More broadly: don't assume Hooman is attached to prior decisions; he optimizes forward.
