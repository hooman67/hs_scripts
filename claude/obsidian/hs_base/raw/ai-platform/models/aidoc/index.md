# Model Hub

> **⚠️ Not in active development — CI disabled**
> The `Models` and `Models.DependencyChecks` CI workflows are disabled. Model Hub CI had not run for an extended period, causing dependency lock files to become stale after Artifactory package updates — locks were never refreshed to reflect the changes. If you intend to revive this, update the lock files and re-enable the workflows.

[Request for comments](https://adobe.sharepoint.com/:w:/r/sites/GenTechWorkingGroup/_layouts/15/Doc.aspx?sourcedoc=%7BF62DC676-52F8-4A0F-8F6A-1A60E41B825E%7D&file=Model%20Hub%20RFC%20-%20v2.docx&action=default&mobileredirect=true) | Follow progress at: [FFP-47740 - 25Q3](https://jira.corp.adobe.com/browse/FFP-47740), [FFP-54047 - 25Q4](https://jira.corp.adobe.com/browse/FFP-54047)

The model hub's goal is allow opinionated sharing of forward execution of ML models.

The only required python file is  `__init__.py` that needs to
1. Export an [models.hub.AIModel](models.hub.AIModel)
2. Be importable without any extra dependency installed.

We don't impost any other structure on python files, but the following is recommended:

| | |
|-- | --|
| `model.py` | If there is any other symbols you want to export from your code, place here (e.g. the original `torch.nn.Module`) |
| `_private/*` | All internals of the model, that users are not expected to import directly. |
