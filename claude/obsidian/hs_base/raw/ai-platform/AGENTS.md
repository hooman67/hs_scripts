This repository is a collection of self contained folders (virtual repos). All the folders with a `.vscode` at the root are a standalone folder.

## Important conventions

### Documentation

The only things that are shared at the root level are the documentation files. All `README.md` files and all `.md` files contribute to the documentation. To verify that the documentation still builds use
the command
```
./gtools docs build
```
at the root of the repo.
