2026-10-20 — VERIFIED SDK compatibility: OpenAI SDK 3.35.1 exposes `input_fidelity` for image edits, but `gpt-image-2.5-sunburst` currently rejects it with HTTP 400 `invalid_input_fidelity_model`. Feature presence in an SDK signature does not prove model support. Omit it for Sunburst; do not automatically retry a failed generation POST. Also, Colligo's error adapter expects HTTP exception detail to be a string, so raw Pydantic error lists can turn an intended 422 into a secondary 500.
